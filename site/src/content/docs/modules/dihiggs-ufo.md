## Scientific Responsibility

The `dihiggs_ufo` repository provides Universal FeynRules Output (UFO) models, MadGraph integration interfaces, and Pythia 8 decay configurations for Monte Carlo event generation:

- **Pack A**: Frozen production baseline (`pi_ufo_baseline_v1_frozen_hotfix1.zip`, SHA-256: `58f1e976...`).
- **Pack A MC**: Multi-seed integration stability studies (30 independent seeds, Birge ratio 0.99).
- **Pack AA**: Pythia 8 decay mechanics, lifetime, and branching ratio validation.
- **Pack B**: Candidate infrastructure and operator preflight suite.
